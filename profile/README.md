# edu-agent-lab

교사는 수업 하나를 준비하기 위해 수업계획안을 쓰고, 교육과정을 확인하고, 퀴즈와 활동지를 만드는 과정을 반복합니다. 이 작업들은 매번 여러 도구를 오가야 해서 시간이 많이 듭니다.

이 저장소는 생성형 AI와 외부 서비스를 활용해 이 문제를 실제로 쓸 수 있는 서비스 형태로 풀어보는 과정을 담고 있습니다. MCP로 외부 서비스를 다루는 법부터 시작해, 이를 하나의 에이전트로 통합하는 것까지 단계적으로 진행합니다.

## 프로젝트 구성

각 프로젝트는 독립적으로 수행 가능하도록 설계되어 있지만, 실전 프로젝트 1·2에서 구현한 내용을 바탕으로 종합 프로젝트에서 하나의 서비스로 확장·통합하는 방향으로 진행합니다.

| 단계 | 프로젝트 | 내용 |
|---|---|---|
| 1 | [Notion 페이지 검색 및 요약] | MCP 클라이언트를 직접 구현해 Notion 팀스페이스에서 자연어 질의로 페이지를 검색·요약 |
| 2 | [AI 챗봇 기반 수업계획안 생성] | 챗봇을 통해 수업계획안을 생성하고 외부 서비스와 연동 |
| 종합 | [AI 기반 수업 활동 에이전트 서비스] | 여러 외부 서비스를 엮어 다양한 수업자료를 생성하는 에이전트로 통합 |

프로젝트 1, 2에서 만든 MCP 클라이언트와 챗봇 로직은 `packages/`에 공통 모듈로 두고, 종합 프로젝트에서 가져다 확장합니다.

## 저장소 구조

```
edu-agent-lab/
├── packages/       # 프로젝트 간 공유되는 핵심 로직 (MCP 클라이언트, 요약, 챗봇 코어)
├── apps/           # 프로젝트별 실행 가능한 서비스
├── docs/           # 프로젝트별 설계 문서, 와이어프레임
└── tests/
```

각 프로젝트의 상세한 구현 방식과 MCP 연동 방식은 `apps/` 하위 각 프로젝트 폴더의 README를 참고해 주세요.
